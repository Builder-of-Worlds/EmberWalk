# fixtures/meta

Answers from the Meta Model API used by the offline tests in `packages/meta/`. Synthetic content only.

- `tool-call.json`: a Muse Spark Responses answer with one `judge_detection` function call whose arguments pass the schema, after a `reasoning` item.
- `tool-call-malformed.json`: a call with arguments that fail the schema (negative frame, a string for `keep`, a plant state on a wood pile, an empty reason).
- `tool-final.json`: the answer after the tool result is sent back.
- `box-probe-test-yard-2-answers.json`: every raw answer of the two live box probe passes on the second test yard (Muse Spark gives a box, SAM 3.1 tracks it), keyed `pass1-` or `pass2-` plus the request fingerprint. 12 Muse Spark answers and 12 SAM answers; every one found its hazard.
- `transcribe.json`: a Muse Voice Transcribe answer in `ENDPOINTING` mode, three timed turns (milliseconds) about a made up yard, one with spaces to trim. Shaped, not recorded, from https://dev.meta.ai/docs/api-reference/voice/transcribe and https://dev.meta.ai/docs/speech-to-text, read Tuesday Oct. 27th, 2026.
- `box-probe-test-yard-2-rows.json`: the 6 scored rows of each pass (hazard, prompt frame, the Muse Spark box in grid units and pixels, hits, cost) with the fingerprints (`sparkFingerprint`, `samFingerprint`) that name the answers above.
- `box-probe-hero-rows.json`: the 6 scored rows of each of two live passes on the hero house sample walk (`fixtures/synthetic/test-yard-2/import/walk.mp4`, scored against `fixtures/synthetic/hero-before/truth.json`), recorded unchanged. Muse Spark found no box for the dry plants by the garage on any of its 3 frames; for the dry brush on the left it drew a box on frames 31, 34 and 37, and SAM 3.1 followed the frame 31 box on 11 of 12 frames in both passes.
- `box-probe-hero-answers.json`: the one SAM 3.1 answer the beat page replays (pass 1, the frame 31 box, tracked frames 27 to 39), keyed `pass1-` plus its `samFingerprint`. It keeps the response `id` and `status`, `usage.video_frames_processed`, and the message's `role` and text, whose lines are the frame number, object number and box record exactly as SAM wrote them. It drops the masks, every other field of the response and of the message item (including the `usage` token counts, all zero), and the text's trailing newline. The other answers of the run are not kept, so the other fingerprints in the rows file name nothing here.

Source: `tool-call.json` and `tool-final.json` are recorded unchanged from a live `muse-spark-1.3` round trip run on Monday Oct. 26th, 2026 (`packages/meta/test/meta.live.test.ts`). The two `box-probe-test-yard-2-` files are recorded unchanged from the live run of `packages/meta/test/box-probe.live.test.ts` on Tuesday Oct. 27th, 2026 (second pass of the day; the first run's answers did not complete and are not kept). The two `box-probe-hero-` files come from the live run of `packages/meta/test/box-probe.live.test.ts` on Saturday Oct. 31st, 2026 at 3:06 PM: the rows file as recorded, the answers file cut down as described above. `tool-call-malformed.json` is shaped from https://dev.meta.ai/docs/tool-calling and https://dev.meta.ai/docs/api-reference/responses/schemas, read Monday Oct. 26th, 2026.
